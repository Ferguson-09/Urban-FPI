# Urban FPI

Urban FPI is a modern streetwear fashion website that combines urban culture, minimal design, and modern web development. The website showcases a clothing brand concept while demostrating front-end development skills using HTML, CSS, and JavaScript. 

This project was created as part of a web development assignment to practice layout design, responsive styling, and user interaction.

---

## Features

- Clean and modern streetwear-inspired design
- Responsive navigation header
- Stylish Contact Page with form
- Embedded Google Maps location
- Social media icons for brand connection
- Organized HTML and CSS structure
- Background image and modern UI styling

---

## 🛠️ Technologies Used

- HTML – Structure of the website
- CSS – Layout and styling
- JavaScript – Basic interaction
- Font Awesome – Social media icons
- Google Maps Embed – Location display
